## 1. 模块概述

### 1.1 目的

把**上游界面与助手**组装成可在目标设备上运行的**载荷**，并保证它「**能装进去、能起来、不臃肿、能升级、能如实报错**」：

1. **组装**：从上游构建产物原样组装（不改上游源码，宪法 A4）；
2. **裁剪**：删除设备上**用不到**的四类内容（纯收益，但必须**先删后验**，见 §3 FR-102-006）；
3. **投放两条路线**：①只读直读（首选，零解压）②归档 + 由运行时自解包（仅当载荷必须可写）；
4. **可写外置**：只把**缓存类**目录指向应用私有可写目录，**不**复制整份载荷；
5. **幂等**：任何解包/物化都必须有**内容级**幂等判据（不是「目录存在」）；
6. **启动脚本**：环境装配 + 进程内托管服务端 + 异常兜底 + 独立日志（在载荷内，仍属本模块交付物）。

### 1.2 解决的问题

| 问题 | 不解决的后果 |
|---|---|
| 载荷怎么带进 HAP | 主界面起来后无内容（`/` 404） |
| 体积（现 payload 884,167,367 B / ≈27.2k 文件，归档 156,592,393 B） | 包体超预算、首启慢（R5/R6） |
| 设备侧只有 WebAssembly 版编译器 | 删错文件 ⇒ 服务起不来，或触发**联网补下载**（O2） |
| 载荷需要可写缓存 | 直接写安装目录（只读）失败；或用系统侧解压器写出**运行时读不到**的文件（硬约束 ④） |
| 幂等判据用「目录存在」 | 就地升级不生效（🔶 旧壳教训） |
| 启动脚本依赖当前目录/可执行路径 | 真机 `cwd=/`、`execPath=/system/bin/appspawn` ⇒ 全链解析失败 |

### 1.3 范围

| 含 | 不含（归属） |
|---|---|
| 上游产物的**组装**与版本固定 | 上游源码改造（A4 禁止；补丁 ≤2 条且幂等可反向） |
| **四项裁剪**与逐项验证 | 运行时二进制投放（**101**） |
| 两条投放路线的**载荷侧**契约（只读直读 / 归档自解包 + marker） | 投放的 **host 侧流水线脚本**是否需要与运行时投放合并（101 的 `scripts/` 纪律） |
| 可写缓存外置策略（`NEXT_*`/临时目录指向私有目录） | 会话/凭据目录的具体文件名（由上游决定，本模块只定根） |
| 载荷内的**启动脚本**：环境装配 + 进程内托管服务端 + 异常兜底 + 独立日志 | 就绪探活与状态机（**101**）、渲染（**103**） |
| 把**预置资源**（同名工具扩展、预置模板）放进载荷并约定落点 | 扩展的**行为实现与真机验证**、工作区主目录清单（**106**）；模板**不覆盖**用例亦在 106 |
| 体积实测与账目更新（回写数据模型文档） | 上架材料与许可清单（**107**） |
| 幂等（内容级）与首启代价的可观测 | 加载页/进度展示的**视图**（**103**） |

## 3. 功能需求

### 3.1 组装与版本（FR-102-001 ~ FR-102-004）

- **FR-102-001** 载荷**必须**由上游**构建产物原样组装**；**必须不**改造上游源码；若确需补丁，补丁**必须**幂等、可反向，且总数**必须** ≤ 2 条（当前登记 0 条）。
- **FR-102-002** 组装**必须**可重复执行并**可校验**：来源版本固定（tag/分支），组装结果**必须**可记录摘要（用于「这次包里到底是哪一版」）。
- **FR-102-003** 载荷**必须**包含运行设备上所需的**全部运行期依赖**（完整依赖树或等价的可解析结构）；**必须不**依赖运行期联网补齐。
- **FR-102-004** 设备侧的**编译/转换能力必须走 WebAssembly 版**；**必须不**随包携带仅适用于其它操作系统的原生二进制；WASM 版落点**必须**在位（缺它则服务起不来）。

### 3.2 裁剪（FR-102-005 ~ FR-102-007）

- **FR-102-005** 载荷**必须**裁掉下列四类内容：① 仅用于构建期追踪的诊断清单文件；② 非目标平台的编译器原生件；③ 图像处理原生件（界面已声明图片不做服务端优化）；④ 伪终端模块（终端功能平台不可用、不提供）。
- **FR-102-006** 裁剪**必须**「**逐项删除、逐项验证**」：每删一项后**必须**在**离线**真机上验证服务仍能起来；任一项导致起不来**必须**回退该项（保持「能起」优先）。
- **FR-102-007** 裁剪后**必须**确认**没有触发联网补下载**（判定物：出现/不出现下载临时目录），并**必须**把结论写进文档。

### 3.3 投放路线（FR-102-008 ~ FR-102-011）

- **FR-102-008** 首选路线：载荷**必须**放在**只读安装资源目录**，由运行时**直读、零解压**；**必须不**在首启做任何解包动作。
- **FR-102-009** 备选路线（仅当载荷**必须可写**）：载荷**必须**打成**单个归档**，由**运行时自己**解包到应用私有可写目录；**必须不**由系统侧（宿主）解压器写业务文件（谁写谁读）。
- **FR-102-010** 可写需求**必须**靠**把缓存类目录指向私有可写目录**解决；**必须不**为此把整份载荷再复制/解包一份。
- **FR-102-011** 幂等判据**必须**是**内容级**（归档摘要 + 内容清单）；**必须不**以「目录存在」「时间戳新」为判据；判据命中**必须**打印「已就位（跳过）」并附判据内容。

### 3.4 载荷内启动脚本（FR-102-012 ~ FR-102-017）

- **FR-102-012** 载荷入口解析与工作目录**必须**使用**绝对路径**；**必须不**依赖当前工作目录与可执行文件路径（真机分别为 `/` 与 `/system/bin/appspawn`）。
- **FR-102-013** 服务端**必须**在**同一进程内**托管；**必须不**使用命令行入口（命令行程序会注册信号处理并结束整个进程）。
- **FR-102-014** 环境装配**必须**在起服务**之前**完成，且**必须**包含：数据根、临时目录、离线开关、代理绕过、监听策略；应用语义变量**必须**只有一处落点（与 FR-101-016 同纪律）。
- **FR-102-015** 载荷**必须**带三个**同名工具扩展**（命令执行 / 按名查找 / 按内容搜索），且其输出**必须**写明与内建行为的差异（忽略规则更宽、单文件大小上限、不解析版本控制忽略文件）；**必须不**声称与外部程序行为逐项一致。
- **FR-102-016** 载荷**必须**带**预置配置模板**，且**必须**只在缺失时写入（**必须不**覆盖用户已有配置）。
- **FR-102-017** 载荷**必须**自装**未捕获异常/未处理拒绝**兜底并写**独立**日志文件；**必须不**调用进程退出（保留现场给运行时取证）。

### 3.5 体积、可观测与边界（FR-102-018 ~ FR-102-022）

- **FR-102-018** 体积**必须**有**实测账**：组装后总大小与文件数、归档后大小、签名包体；**必须不**用线性外推估算（被删项压缩比高于均值）。
- **FR-102-019** 离线**必须**可完整跑通：**必须不**自动安装插件、**必须不**下载外部搜索二进制；被禁止的行为**必须**以可见日志/提示出现。
- **FR-102-020** 载荷就位后**必须**能被运行时**全链解析**（依赖解析无「找不到模块」）；只读目录的**读取边界**（大文件、内存映射）**必须**实测记录。
- **FR-102-021** 会话、凭据、缓存、日志**必须**落在应用私有可写目录；**必须不**写入只读安装目录；幂等 marker **必须**落在可写目录（不污染载荷内容）。
- **FR-102-022** 首启代价**必须**可观测：直读路线无可观测解压阶段；自解包路线**必须**有阶段文本与可重试语义（重试 = 重新解包，**不是**重启运行时）。

## 5. 验收场景（Given / When / Then）

- **AC-102-01 只读直读成立**：Given 载荷已随包投放到只读安装目录；When 真机冷启动；Then `/` 返回 200 且依赖**全链解析无「找不到模块」**，且**无可观测解压等待**（首启计时与阶段文本互证）。
- **AC-102-02 裁剪 1 生效**：Given 已删除全部诊断清单文件；When 离线真机启动；Then 服务起来且日志无「找不到模块」。
- **AC-102-03 裁剪 2 生效且无补下载**：Given 已删除非目标平台编译器目录；When 断开网络启动；Then 服务起来，且下载临时目录**不出现**。
- **AC-102-04 裁剪 3 生效**：Given 已删除图像处理原生件；When 走一遍含图片的界面路径；Then 日志**无**相关报错（图片不优化的声明生效）。
- **AC-102-05 裁剪 4 生效**：Given 已删除伪终端模块；When 正常使用会话与工具；Then **无**任何代码路径尝试加载该模块（日志无相关「找不到模块」）。
- **AC-102-06 体积账更新**：Given 裁剪完成；When 量测；Then 三项实测值（组装后 / 归档后 / 签名包）**写入数据模型文档**，且签名包体积与预算对照。
- **AC-102-07 幂等是内容级**：Given 第二次启动且归档未变；When 观察日志与 marker；Then 出现「已就位（跳过）」且 marker 内容 = 归档摘要；Given 归档被改动；Then marker 变化并**重新**就位。
- **AC-102-08 进程内托管**：Given 载荷就位；When 启动；Then `/` 返回 200 且页面含界面标记；至少一条 `/api/*` 返回 200。
- **AC-102-09 只读边界如实**：Given 尝试向只读安装目录写入；Then **失败且报错可读**（不是静默成功）；Given 写应用私有目录；Then 成功且可读回。
- **AC-102-10 扩展差异可见**：Given 使用「按内容搜索」；When 看输出；Then 输出**含**跳过规则与单文件上限说明，且**不**声称与外部程序一致。
- **AC-102-11 模板不覆盖**：Given 用户已改过配置文件；When 重启应用；Then 文件内容**保持**用户版本（只有缺失时才写预置内容）。
- **AC-102-12 离线可用**：Given 断开外网；When 冷启动到「可输入消息」；Then 全流程可用，日志**无**联网安装/下载尝试。

## 7. 假设与约束

1. **上游形态固定**：服务端框架为**非 standalone** 构建（✅ 上游未配置 standalone）⇒ 载荷**必须**带完整依赖树或等价结构；上游版本固定，升级逐条复核（R12）。
2. **设备侧编译器只有 WASM 版**（✅ 上游产物内存在）⇒ **WASM 可用是硬前置**，进而 **JIT/授权面是硬前置**（`--jitless` 下 WASM 全废）。
3. **平台缺口**：无版本控制程序、无外部搜索二进制、无 PTY ⇒ 由同名扩展顶替并**如实写明差异**（A6）。
4. **只读目录能力边界未定**：安装目录内数万小文件的读取可接受性、能否内存映射 ⬜ 待验证（决定路线 ①/②，A1/A6）。
5. **裁剪收益是预估**：四项体积为实测，**收益为压缩后预估**（⬜），必须实测（R5）。
6. **谁写谁读**：系统侧解压器写出的文件运行时读不到（硬约束 ④）⇒ 解包只能由运行时自己做（库宪法 C3）。
7. **符号链接不可用** ⇒ 一切资源物化用**复制**，不得用符号链接。
8. **载荷内不得出现宿主应用语义的假设**：启动脚本只做「环境 + 入口 + 服务 + 日志」，不做界面与鉴权决策（A1/A2）。
