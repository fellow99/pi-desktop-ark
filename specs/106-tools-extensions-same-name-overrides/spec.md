# spec.md —— `106-tools-extensions-same-name-overrides` 工具扩展（同名顶替）

> 用「同名顶替」补齐平台缺口；并让「工作区主目录清单」在助手侧可见、可自检。
> 依据：规划 [`../../docs/000-工程规划.md`](../../docs/000-工程规划.md) **§5 第 5 条**、**§8.1**（能力对齐矩阵中 `bash`/`find`/`grep` 三行）、**§8.3**（旧壳资产复用清单）、

## 1. 模块概述

### 1.1 目的

助手在本平台上**必须**能「按内容搜索、按名递归找文件、执行 shell 命令」，而平台的三个缺口中：
内建 `bash` 依赖子进程结束事件（旧壳实测**永不送达**）、内建 `find`/`grep` 依赖设备上**不存在**的 `fd`/`rg`，
且离线策略**禁止**下载它们。本模块用**随包的同名扩展**顶替这三个工具，并把「工作区主目录清单」接上，使「选择工作目录 → 助手在里面干活」闭环成立。

### 1.2 解决的问题

| # | 症状 | 后果 | 本模块处置 |
|---|---|---|---|
| 1 | 内建 `bash` 在真机**永久挂住**（等 `exit`/`close`，且**无**默认超时） | 会话卡死、用户只能重开应用 | 常驻 shell + **输出哨兵行**判定结束 + 120 s 默认超时 |
| 2 | 内建 `find`/`grep` 需要 `fd`/`rg`，设备上不存在且禁止下载 | 「按内容搜索 / 按名查找」实质不可用 | 纯 JS 走查顶替（零子进程、零网络） |
| 3 | 命令里的顶层 `exit` 会打断常驻 shell（同型实现的老问题） | 一条 `exit 1` 就得重启 shell | **子 shell 括号组**执行：`exit` 只结束子 shell |
| 4 | 超时/中止后的旧命令子进程继续往同一管道写 | 后续命令结果被迟到输出污染 | 进程组整体杀 + 每条命令一个状态对象 + 身份判断丢弃迟到数据 |
| 5 | 工作目录对话框缺主目录（链路断掉表现为「少了一个 Tab」） | 用户找不到能用的根，且难以归因 | 工作区主目录清单 + `/roots` 自检（消费 `104` 的供数） |
| 6 | 首次运行没有配置模板 / 或反过来把用户改过的配置覆盖掉 | 助手行为不确定 / 用户改动丢失 | 预置模板**只在缺失时写**（不覆盖用户文件） |
| 7 | 后台自动安装插件或下载二进制 | 违反离线策略与合规（不可见的外联） | 离线旗标 + 「仅本地源」策略 + 被禁止行为必须可见 |

### 1.3 范围

**做**：三个同名工具扩展（`bash`/`find`/`grep`）与两个辅助扩展（运行时事实、工作区主目录自检）的**搬入与适配**；两份预置模板；
工作区主目录清单在助手侧的消费与自检；`PI_OFFLINE` 等离线策略；上游补丁策略（幂等、可反向、预计 0–2 条）。

**不做**（明确排除）：

| 不做 | 归谁 / 依据 |
|---|---|
| 终端面板 / PTY | 平台不可用（规划 §8.4；宪法 A6：如实说明，不做假终端） |
| 版本控制 / worktree | 设备无 `git`（同上） |
| 把「看起来能用」的替代入口做出来 | 宪法 A6 明确禁止 |
| 宿主侧权限/选择器实现 | `104`（本模块只**消费**清单与预检结果） |
| 载荷组装与裁剪流水线 | `102`（本模块只定义扩展与模板在载荷里的落点与投放规则） |
| 联网安装插件 / 下载外部二进制 | **禁止**（离线形态，`FR-ARK-029`） |

## 3. 功能需求（RFC 2119）

### 3.1 同名顶替（`bash` / `find` / `grep`）

- **FR-106-001** 上述三个工具**必须**由**随包**的同名扩展提供（顶替内建实现），**必须不**依赖设备上存在或下载 `rg`/`fd`/其它外部程序。
- **FR-106-002** 命令执行的结束判定**必须**只使用**可判定的输出记号**（唯一随机结束标记行），**必须不**依赖子进程的退出/关闭事件（`FR-ARK-033`）。
- **FR-106-003** 命令执行**必须**有默认超时（120 s 量级）；超时**必须**返回可读失败并**保留已经产出的输出**，**必须不**无限等待。
- **FR-106-004** 命令中的顶层 `exit` / `exec` **必须**只结束该条命令（常驻 shell **必须**存活，后续命令仍可用）。
- **FR-106-005** 每条命令**必须**在执行前显式切换到指定工作目录；工作目录不存在时**必须**立即失败并报错，**必须不**让命令悄悄跑在默认目录里。
- **FR-106-006** 命令的**标准输入**必须与命令帧协议解耦（等价于 `/dev/null`）；结束标记**必须不**泄露给被执行的命令（否则读标准输入的命令会把标记吃掉/打印出来）。
- **FR-106-007** 输出**必须**合并标准错误（顺序可读）；超过上限时**必须**按 UTF-8 字节边界截断并**显式标注**已截断（**必须不**切碎多字节字符）。
- **FR-106-008** 同一时刻**必须**只允许一条命令在常驻 shell 上执行（严格串行化）；空闲时**必须不**启动新 shell（常驻复用）。
- **FR-106-009** 无法取得退出码时（超时/被中止/shell 意外退出）**必须**明确说明「退出码未知」，**必须不**伪造成 `0`。

### 3.2 搜索与查找（纯 JS）

- **FR-106-010** 搜索/查找**必须**零外部二进制、零网络、零子进程；遍历**必须**是有界算法（文件数上限、深度上限、结果上限）。
- **FR-106-011** 输出**必须**写明：扫描/读取的文件数、跳过的规则（点开头目录、依赖目录、版本控制目录）、单文件大小上限、深度上限、结果上限触顶状态；**必须不**声称与外部程序行为逐项一致（`FR-ARK-036`）。
- **FR-106-012** 单文件读取上限**必须**为 **512 KiB**（超过即跳过并计数）；不可读条目**必须**跳过并计数，**必须不**让整次搜索失败。
- **FR-106-013** 模式语义**必须**在其帮助文本与输出说明中如实描述（支持通配、跨段匹配、花括号枚举、字符类；全小写模式大小写不敏感）；非法模式**必须**报错，**必须不**静默退化为「不过滤」。

### 3.3 工作区主目录清单与自检

- **FR-106-014** 应用**必须**提供一条**自检命令**，输出四个工作区主目录（沙箱/桌面/文档/下载）的：绝对路径、是否存在、是否可读、授权状态。
- **FR-106-015** 授权状态**必须**来自宿主能力（`104` 的权限预检）；桥/能力不可用时**必须**显示「不可判定」，**必须不**猜测。
- **FR-106-016** 授权状态与「真实可用性」**必须**分开陈述：预检可能**假阴性**（已授权仍报未授权）⇒ 以**真实读目录结果**为准，界面/输出**必须**说明这一点。
- **FR-106-017** 清单来源**必须**是**单一来源**（环境变量 `PI_HOS_ROOTS`，由 `104` 供给）；未设置或非法时**必须**如实报错并说明「期望的四个主目录」，**必须不**回退到其它根。

> **2026-10-19 口径变更**：根清单由宿主声明，**现只有「沙箱」一个**——`desktop`/`documents`/`download`
> 三个根随 `READ_WRITE_{DESKTOP,DOCUMENTS,DOWNLOAD}_DIRECTORY` 撤销申请而移除（`docs/001-能力复刻评估.md`
> REV-5·REV-6，零 ACL 评估见 `docs/ACL-无ACL评估.md`）。上两条 FR 里的「四个」按现状读作「宿主声明的
> 全部根」（现一个），自检命令与报错文案同步改为一个。

### 3.4 预置模板与离线策略

- **FR-106-018** 应用**必须**提供预置模板（shell 路径、默认工具集、MCP 服务器空表），并**只在目标文件缺失时**写入；**必须不**覆盖用户已修改的同名文件（`FR-ARK-024`）。
- **FR-106-019** 应用**必须**默认工作于「离线 / 仅本地源」：**必须不**在后台自动安装插件或下载外部二进制；被禁止的行为**必须**以可见提示出现（`FR-ARK-029`）。
- **FR-106-020** 扩展**必须**自包含：只依赖运行时内置模块，**必须不**导入上游内部路径（降低上游升级的破碎面）；扩展工厂内**必须不**创建长驻资源（进程/定时器/监听器）。

### 3.5 上游补丁与平台缺口

- **FR-106-021** 若确需上游补丁：**必须**幂等、可反向、追加到补丁列表末尾，且**必须不**落在既有补丁的上下文区间；预计**0–2 条**。
- **FR-106-022** 工作目录/主目录的消费点**应当**直接沿用旧壳已验证的补丁，**必须不**另造一条同义补丁。
- **FR-106-023** 平台缺口（无 `git`、无 `rg`/`fd`、无 PTY、无后台常驻）**必须**如实降级并在界面/文档中说明；**必须不**提供「看起来能用」的替代入口（`FR-ARK-039`）。
- **FR-106-024** 工具的输出**必须**让调用方（模型）能自行判断「结果是否完备」：上限触顶、跳过项、截断**必须**逐项写出。

## 4. 关键实体

### 4.1 工具清单（同名顶替关系）

| 工具名（对模型透明） | 顶替对象 | 结束/结果判定 | 主要上限 | 关键差异（必须知道） |
|---|---|---|---|---|
| `bash` | 内建 `bash`（依赖子进程事件） | **输出哨兵行**（含随机记号 + 退出码） | 默认超时 120 s；输出 256 KiB | 常驻 shell；每条命令在子 shell 内（`cd`/变量不跨调用）；stderr 合并；**无**文件围栏 |
| `grep` | 内建 `grep`（需 `rg`） | 纯 JS 行匹配 + 结果上限 | 单文件 512 KiB；结果默认 100；深度 8 | 不解析忽略文件；跳过点目录/依赖目录/版本控制目录 |
| `find` | 内建 `find`（需 `fd`） | 纯 JS 遍历 + 通配匹配 | 结果默认 1000；文件数 2000；深度 8 | 同上；全小写模式大小写不敏感 |
| （辅助）运行时事实命令 | 旧壳同名命令 | 直接输出文本 | — | 反映**本工程**的运行时事实（不得照抄旧壳「Electron 主进程」措辞） |
| （辅助）工作区主目录自检命令 | 旧壳 `/roots` | 直接输出文本 | — | 授权状态来自本工程宿主能力（见 `FR-106-015`） |

### 4.2 预置模板实体

| 文件 | 内容语义 | 写入规则 |
|---|---|---|
| shell 配置 | 解释器绝对路径 + 默认工具集 | **仅缺失时写** |
| MCP 配置 | 服务器表（默认空） | **仅缺失时写** |

### 4.3 工作区主目录记录

字段与形状沿用 `104` 的规格（`id`/`label`/`path`/权限别名），本模块**只消费**：自检命令按项输出「路径 + 状态 + 授权」，授权不可判定时输出「不可判定」。

### 4.4 平台缺口降级表（本模块相关）

| 缺口 | v1 降级 | 必须写出来的话 |
|---|---|---|
| 无 `git` | 版本控制功能不可用 | 「设备无 `git`」（不得用 shell 悄悄顶替） |
| 无 `rg`/`fd` | 同名扩展顶替 | 「近似忽略规则（更宽）+ 单文件上限 512 KiB；不解析忽略文件」 |
| 无 PTY | 不做终端面板 | 「本平台无 PTY，终端面板不提供」 |
| 命令无文件围栏 | 如实说明 | 「命令以应用身份运行，不受文件审批流保护」 |

## 5. 验收场景（Given / When / Then，逐条可证伪）

| 编号 | Given | When | Then（观测点） |
|---|---|---|---|
| `AC-106-01` | 会话已就绪 | 执行一个成功命令 | 输出正确；退出码 `0`；常驻 shell **仍可用**（紧接着再执行一条命令成功） |
| `AC-106-02` | 会话已就绪 | 执行 `exit 3` | 返回**退出码 3**；下一条命令**仍然可用**（shell 未被 `exit` 杀死） |
| `AC-106-03` | 会话已就绪 | 执行一条会超时的命令 | 超时后返回可读失败 + **保留已产出输出**；会话未卡死 |
| `AC-106-04` | 工作目录被指定 | 执行打印当前目录的命令 | 打印出的目录 = 指定的工作目录（不是应用默认目录） |
| `AC-106-05` | 设备上无 `rg`/`fd` | 按内容搜索 / 按名查找 | 两者都能返回结果；输出里**写明**跳过规则与 512 KiB 单文件上限（`TC-106-002`） |
| `AC-106-06` | 搜索触顶 | 观察输出 | 输出里**出现**上限触顶说明（结果数/文件数/深度至少其一） |
| `AC-106-07` | 主目录清单已供数 | 执行自检命令 | 四项主目录各输出路径 + 状态 + 授权；缺项时明确列出「期望的四个主目录」 |
| `AC-106-08` | 宿主能力不可用 | 执行自检命令 | 授权行显示「不可判定（…）」；**没有**把「不知道」写成「未授权」或「已授权」 |
| `AC-106-09` | 用户已修改配置文件 | 重启应用 | 文件内容保持用户版本（**没有**被预置模板覆盖） |
| `AC-106-10` | 应用运行中 | 观察是否有安装/下载行为 | **没有**自动安装插件或下载外部二进制；被禁止的动作有可见提示 |
| `AC-106-11` | 输出超上限 | 执行产生大量输出的命令 | 结果被截断且**显式标注**；标注里给出实际字节数与展示上限 |
| `AC-106-12` | 一条命令无法取得退出码（超时/中止） | 观察输出 | 明确说明「退出码未知」；**没有**出现伪造的 `exit code 0` |

> **禁止的判据**：用「命令好像跑通了」判工具可用；用「日志里出现了某一行」判执行；用 `uitest dumpLayout` 的返回内容判界面输出。
> 每条判据**必须**能从会话界面/工具输出文本（可截图）或 HTTP 端点复现（宪法 A7）。

## 6. 非功能需求

| 编号 | 项 | 要求（可验证） |
|---|---|---|
| `NFR-106-001` | 常驻复用 | 连续多条命令**必须**复用同一个常驻 shell（可观测：命令数与 shell 启动次数不成正比） |
| `NFR-106-002` | 内存 | 搜索**必须**有界：文件数上限、深度上限、单文件上限、结果上限（避免大目录把内存吃光） |
| `NFR-106-003` | 输出体量 | 单条命令输出上限 256 KiB；搜索输出受结果上限约束 |
| `NFR-106-004` | 离线 | 全部能力在无外网环境下可用；不产生任何外联请求 |
| `NFR-106-005` | 自包含 | 扩展只依赖运行时内置模块；升级上游时**不**因内部路径变动而碎 |
| `NFR-106-006` | 幂等投放 | 重复投放扩展/模板**必须**幂等；模板**必须**不覆盖用户文件 |
| `NFR-106-007` | 可诊断 | 每类上限触顶**必须**在输出里可读；不得只在内部计数 |

## 7. 假设与约束

| # | 假设 / 约束 | 影响 |
|---|---|---|
