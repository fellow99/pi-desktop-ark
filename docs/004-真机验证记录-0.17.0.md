## 7. 本轮构建坑（回写 `docs/已知坑-cwd与沙箱路径.md` 同类）

1. **`assemble-payload` 的默认源是 `../pi-desktop-hos/pi-dist`**（`DEFAULT_FROM`）：hos 的 `collect-pi` **必须先于** ark 的 `assemble-payload` 执行，否则 ark 会镜像 hos 上一版的 pi-dist（本轮首建即镜像了 0.15.0 旧树：tarball SHA 变化但 `package.json`/UI 版本仍 0.15.0，被徽标/`/api/app-update` 断言当场抓住）。**正确顺序：npm ci(pi-web) → hos 五段 → ark assemble → ark hvigorw**。marker 是文本标记（补丁内容本身），跨版本同名标记不会缺失，不能作为新鲜度依据；**载荷版本断言必须以包内 `package.json` + 运行时 `/api/app-update` 为准**。
2. 重装（uninstall→install）会清空应用沙箱：DeepSeek Key、工作区、会话全部重置，基本功能链需整套重跑（本轮即如此执行）。
